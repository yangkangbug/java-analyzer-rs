# Binary return composition oracle

Handwritten dependencies are compiled as data. The compiler helper analyzes source
and emits exact binary declaring owner and full JVM descriptor without executing
fixture programs. Predictions precede candidate execution: fourteen supported
return compositions, six conservative refusals, two invalid compiler controls.
Complete normalized native records and legacy baseline remain frozen separately.
Return types do not choose overloads; only an already selected inner declaration
supplies a type, in its own linking scope. Eight scalar types, reference actuals,
chains, inherited declarations and an overload-selected return are exercised.
